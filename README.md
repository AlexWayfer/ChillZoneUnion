# Чиллзон — союз гильдий

Аддон для общего чата, состава и согласованных переходов между «Чиллзон» и «Чиллзон Навсегда» в WoW Forever.

[Релизы](https://github.com/Azired/ChillZoneUnion/releases) · [Полная инструкция](README.txt) · [Модель доверия и ограничения](SECURITY.txt)

## Установка

1. В разделе **Assets** нужного релиза скачайте ZIP `ChillZoneUnion` с номером версии.
2. Закройте игру и распакуйте папку `ChillZoneUnion` в `World of Warcraft\_forever_\Interface\AddOns\`.
3. Включите аддон в игре. Окно открывается командой `/cz` или кнопкой CZ у миникарты.

Для общего чата участникам нужен установленный аддон. Первую связь один раз подтверждают главы или офицеры после проверки полного имени. Затем аддон автоматически выбирает связных среди глав и офицеров с аддоном, обнаруженных через подтверждённое соединение. Назначать и сопрягать каждого вручную не требуется. Для работы нужен хотя бы один такой игрок онлайн в каждой гильдии. Обычные участники связными не становятся.

## Версия 0.6.0-beta

Связные определяются по игровым офицерским правам звания, а не по его названию, номеру или праву приглашать игроков. При выходе или понижении действующего связного аддон выбирает другого офицера. Без офицеров онлайн связь приостанавливается и восстанавливается после их возвращения.

Обновиться должны все участники; старый протокол несовместим, первое соединение гильдий нужно подтвердить заново. Настройки отображения сохраняются. Офицеры остаются доверенными операторами. Перед массовой установкой нужна проверка двух настоящих игровых клиентов. Подробности — в [примечаниях к релизу](.github/releases/0.6.0-beta.md) и [SECURITY.txt](SECURITY.txt).

## Проверки и сборка

GitHub Actions проверяет согласованность версий и запускает обе группы тестов на Lua 5.1. После успешных проверок версия без опубликованного релиза собирается в ZIP из 26 файлов аддона. Перед публикацией проверяются commit тега и контрольная сумма загруженного архива.

Локальная проверка состава пакета: `pwsh ./tools/package.ps1 -ValidateOnly`.
Локальная сборка: `pwsh ./tools/package.ps1`. Архив появится в `build/`.
Обе группы тестов с установленным Lua 5.1: `sh ./tools/test.sh` (в Windows — `wsl -d Ubuntu -- sh tools/test.sh`). Скрипт запускает именно текущий checkout независимо от имени его папки.
