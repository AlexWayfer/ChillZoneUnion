# Чиллзон — союз гильдий

Аддон для общего чата, состава и согласованных переходов между «Чиллзон» и «Чиллзон Навсегда» в WoW Forever.

[Скачать 0.5.0-beta](https://github.com/Azired/ChillZoneUnion/releases/tag/v0.5.0-beta) · [Полная инструкция](README.txt) · [Модель доверия и ограничения](SECURITY.txt)

## Установка

1. В разделе **Assets** релиза скачайте `ChillZoneUnion-0.5.0-beta.zip`.
2. Закройте игру и распакуйте папку `ChillZoneUnion` в `World of Warcraft\_forever_\Interface\AddOns\`.
3. Включите аддон в игре. Окно открывается командой `/cz` или кнопкой CZ у миникарты.

Для общего чата участникам нужен установленный аддон. Первую связь настраивают главы или офицеры с игровым рангом 0–1: новый контакт подтверждается на второй стороне после проверки полного имени. Для работы должны быть онлайн подготовленные и одобренные связные обеих гильдий. Подробности настройки, резервов и переходов — в [README.txt](README.txt).

## Версия 0.5.0-beta

Исправлены ошибки контроля доступа. Обновиться должны все участники; прежнее соединение нужно настроить заново. Версию **0.4.6 не используйте** для межгильдейского соединения.

Одобренные связные остаются доверенными операторами. Перед массовой установкой проверьте соединение в игре и переключение на подготовленные резервы. Подробности — в [примечаниях к релизу](.github/releases/0.5.0-beta.md) и [SECURITY.txt](SECURITY.txt).

## Проверки и сборка

GitHub Actions проверяет согласованность версий и запускает обе группы тестов на Lua 5.1. После успешных проверок версия без опубликованного релиза собирается в ZIP из 26 файлов аддона. Перед публикацией проверяются commit тега и контрольная сумма загруженного архива.

Локальная проверка состава пакета: `pwsh ./tools/package.ps1 -ValidateOnly`.
Локальная сборка: `pwsh ./tools/package.ps1`. Архив появится в `build/`.
